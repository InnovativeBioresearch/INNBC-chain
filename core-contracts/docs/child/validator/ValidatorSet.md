### initialize

```solidity
function initialize(uint256 newEpochSize) external nonpayable
```

Initializes epoch tracking during genesis.

*Runtime-bytecode genesis allocations do not execute the constructor. The system-caller restriction therefore also protects those allocations.*

#### Parameters

| Name | Type | Description |
|---|---|---|
| newEpochSize | uint256 | Epoch length in blocks; must be at least two. |
