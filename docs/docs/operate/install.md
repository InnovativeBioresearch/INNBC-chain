# Install INNBC Chain

INNBC Chain is installed from the production nodeclient bundle generated by this repository.

The current production deployment flow does not use the removed legacy Polygon Edge Docker image, rootchain deployment, bridge setup, StakeManager, SupernetManager, or burn-contract flow.

## Build The Nodeclient Bundle

From the repository root:

```bash
make nodeclient
```

This creates:

```text
dist/innbc-nodeclient/
dist/innbc-peerdirectory-service/
```

## Install The Nodeclient On A Server

Copy the `dist/innbc-nodeclient` folder to the server and place it under:

```text
/opt/innbc-nodeclient
```

Then run:

```bash
sudo /opt/innbc-nodeclient/scripts/install.sh
```

The installer places the node binary and service files in the standard runtime locations:

```text
/usr/local/bin/innbc-chain
/etc/innbc/
/var/lib/innbc/
/var/log/innbc/
/etc/systemd/system/innbc-node@.service
```

The nodeclient installer does not create or overwrite validator identity folders. Validator identities are managed explicitly with the `innbc-chain node` commands.

## Install The Peer Directory Service Package

Copy the `dist/innbc-peerdirectory-service` folder to the server and place it under:

```text
/opt/innbc-peerdirectory-service
```

Then run:

```bash
sudo /opt/innbc-peerdirectory-service/scripts/install.sh
```

The peer-directory installer installs only peer-directory service files. It does not touch the node binary, genesis, node env files, validator keys, or chain data.

## Verify The Installed Binary

```bash
innbc-chain version
```

## Next Steps

After installation, create or prepare validator identity folders, register validators, and start the systemd-managed node services.
